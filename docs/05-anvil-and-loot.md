# Bait System (Fishing)

Replaces Lure. Fishing rods become simple rods. Craftable baits held in the offhand. Luck of the Sea stays as an enchantment (altering luck is magical).

# XP Economy

XP is the universal equipment progression currency. Consumed by four systems:

| System | XP Consumption | Examples |
|---|---|---|
| Enchanting Table | Levels per enchantment | Fortune III ≈ 8 levels, Fire Aspect I ≈ 2 levels |
| Smithing Table | Levels per upgrade | Copper (1), Iron (3), Gold (5), Diamond (8), Netherite (12) |
| Mending | XP orbs repair instead of filling bar | Each orb = 2 durability, 0 XP for player |
| Anvil (rename) | 1 level fixed | Negligible but exists |

The Mending dilemma: every Mending item drains XP that could go toward a new enchantment or smithing upgrade. Remove Mending gear before farming if you want to save your levels.
