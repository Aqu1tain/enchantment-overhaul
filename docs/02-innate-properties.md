# System 2: Innate Material Properties

Specialized protections are no longer enchantments. They are intrinsic properties of the armor material.

## Resistances

| Material | Innate Resistance | Justification |
|---|---|---|
| Copper | Fire | Molten metal, heat-treated |
| Iron | Projectiles | Heavy, dense, stops arrows |
| Diamond | Explosions | Hardest material |
| Gold | Magic | High enchantment affinity in vanilla |
| Netherite | Fire | Already doesn't burn in lava |
| Leather | None | It's leather |

## Scaling

The bonus scales with the number of pieces worn. Full set = full bonus. Two pieces = half bonus. Mixed sets become a strategic choice.
