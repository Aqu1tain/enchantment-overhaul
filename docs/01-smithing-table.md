# System 1: Smithing Table — Stat Boosts

Templates found in structures determine the upgrade type. The material in the second slot determines the level. One upgrade per category per item. Each upgrade leaves a visual mark on the 3D model and inventory sprite, cumulative with cosmetic trims.

## Templates

| Template | Replaces | Effect | Sources |
|---|---|---|---|
| Honing | Sharpness, Power, Density | Weapon damage | Weaponsmiths, Pillager Outposts, Strongholds |
| Warding | Protection | General damage reduction | Armorer houses, Bastions |
| Tempering | Unbreaking | Durability | Toolsmiths, Mineshafts |
| Grinding | Efficiency | Mining/tool speed | Mineshafts, Trial Chambers |
| Stringing | Quick Charge | Reload speed | Pillager Outposts |
| Cushioning | Feather Falling | Fall damage (boots) | Villages |

## Levels and XP Cost by Material

| Material | Level | XP Cost |
|---|---|---|
| Copper | I | 1 level |
| Iron | II | 3 levels |
| Gold | III | 5 levels |
| Diamond | IV | 8 levels |
| Netherite | V | 12 levels |

## Visual Changes

Each upgrade leaves a visible mark. Upgrades stack with each other AND with cosmetic trims. Two visual layers: mode (trims) + function (smithing).

- **Honing**: blade/edge color changes based on material
- **Warding**: rivets or metallic bands on armor
- **Tempering**: golden/metallic band around the handle
- **Grinding**: shine/brilliance on the tool head
